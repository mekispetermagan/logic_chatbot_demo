ACTIVE DOMAIN: objects
Stored attributes: color (red blue green yellow), size (small medium large),
shape (bloom spark drop loop). Shape aliases: flower=bloom, star=spark,
tear=drop, ring=loop. There are no spheres, cubes or pyramids.
Properties include these values and positions. Attribute queries include color,
size, shape, position, row, column. In shared copy/has/removal forms use square
for position; same-row/same-column checks are supported. Every/some predicates
can be descriptors, on the board, have a color/size/shape/square, next to T,
same ATTRIBUTE as T, at the edge, or in a corner. No implicit indefinite targets.
